# 声音克隆工具

这是一个给买家自己操作的本地网页工具：双击 `启动工具.bat` 后浏览器会自动打开，上传参考音频、输入中文或英文文本，点击生成并下载 WAV。

## 接入模型

默认配置使用 Qwen3-TTS 的零样本克隆模式，模型会在第一次生成时加载并在进程内复用；也可以把 GPT-SoVITS、CosyVoice 或其他模型替换到 `config.json` 的命令模板中。命令模板支持以下变量：

- `{reference_audio}`：参考音频绝对路径
- `{text}`：待合成文本
- `{reference_text}`：当前参考音频片段的文字（可选，填写后稳定性更好）
- `{language}`：中文、English 或中英混合
- `{output}`：需要写入的 WAV 路径
- `{output_dir}` / `{output_name}`：输出目录和文件名
- `{device}`：自动检测到的 `cuda` 或 `cpu`

配置中的 `leading_spaces` 用于给开头音频留出短停顿，避免首字音素被截断。
配置中的 `speed` 默认是 `1.15`，用于减少中文短句中过长的停顿；可按音色效果调整到 `1.0` 至 `1.3`。

## 运行和打包

开发运行：双击 `启动工具.bat`。打包：双击 `build_exe.bat`，生成的目录在 `dist/声音克隆工具`，买家双击其中的 `声音克隆工具.exe` 即可。

买家首次使用：先双击 `安装模型.bat`，再双击 `声音克隆工具.exe`。程序会自动检测 PyTorch 的 CUDA 状态：有可用 NVIDIA CUDA 就使用 GPU，否则使用 CPU。配置默认使用 `https://hf-mirror.com` 下载 Qwen3-TTS 模型；建议准备约 10GB 以上磁盘空间。模型权重和第三方模型的商业使用条款需要单独确认；大模型文件建议随安装器首次启动下载，而不是直接塞进 exe。

## 使用流程

打包好的工具在 `dist\声音克隆工具` 文件夹里，操作步骤如下：

1. **进入文件夹**：打开打包后的 `声音克隆工具` 文件夹（即 `dist\声音克隆工具`）。
2. **安装模型**：双击 `安装模型.bat`，等待模型依赖安装完成（首次使用需要，耗时视网络而定）。
3. **启动工具**：安装完成后，双击 `声音克隆工具.exe`，浏览器会自动打开操作页面。
4. **生成语音**：上传一段参考音频（建议 5–30 秒清晰人声），输入要合成的文字（中/英文均可），点击"生成语音"，完成后可试听并下载 WAV 文件。
